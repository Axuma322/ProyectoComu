# Consigna y alcance

Fuente primaria local: [Escenario hipotético - Transmisión Inalámbrica de Imágenes.pdf](escenario_original.pdf), ocho páginas, revisadas completas. Copia sin cambios del archivo conservado en `recursos/`. Sus requisitos prevalecen sobre este diseño.

La [matriz](matriz_requisitos.md) distingue obligaciones, recomendaciones, recursos ofrecidos y optimizaciones opcionales. Todas las verificaciones físicas están **pendientes**. Documentar una solución prevista no prueba cumplimiento.

El título menciona captura, pero la especificación 8 pide extraer una imagen ya almacenada; no se presupone cámara. Debe aclararse con el docente si «bit a bit» se refiere al archivo completo o al raster; se propone preservar ambos en modo sin pérdidas.
