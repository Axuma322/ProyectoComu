# ProyectoComu

Proyecto del curso IE0527 Ingeniería de Comunicaciones de la UCR: **transmisión inalámbrica de imágenes con codificación de fuente**.

Estamos investigando la comunicación entre dos Raspberry Pi Zero mediante radios nRF24 del laboratorio. Usaremos una Pi por extremo y un protocolo propio punto a punto. Todavía debemos identificar las variantes del hardware y probar el enlace; no hay resultados experimentales.

El trabajo actual se concentra en la transmisión. La codificación de fuente se integrará después.
