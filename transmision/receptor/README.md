# Receptor

`escuchar.py` permanece escuchando y muestra los mensajes recibidos hasta Ctrl+C.
Desde la raíz del repositorio: `.venv/bin/python -m transmision.receptor.escuchar`.

Instalación, alimentación y configuración: [prueba mínima](../README.md).
Todavía no se ha probado en hardware. No recibe archivos ni imágenes;
el [protocolo propuesto](../protocolo/README.md) queda para después.
